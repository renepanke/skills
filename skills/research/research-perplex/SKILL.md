# Perplex

Apply `references/writing.md` to all user-facing text before delivery.

1. Use the available web search tool. Carry forward relevant constraints from the conversation, including the location, timeframe, and product version. Start with one focused batch of queries using the terms most likely to surface authoritative sources.
2. Open the best results and verify that they directly support the answer. Prefer sources closest to the facts. For time-sensitive claims, check when the information applied as well as when it was published. Run a targeted follow-up search if a material claim is unsupported or sources disagree.
3. Lead with the answer. Include only details that help answer the question, with direct links next to the claims they support. Flag any unresolved uncertainty that changes the answer. If web access is unavailable, report that the lookup could not be verified.
